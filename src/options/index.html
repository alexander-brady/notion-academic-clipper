Academic Clipper for Notion

Clip papers to a Notion database with their title, URL, DOI and BibTeX entry.

1. Connect your Notion workspace

  1. Open notion.so/my-integrations and create a New integration of type Internal.
  2. Under Capabilities, keep read and insert content enabled.
  3. Copy the Internal Integration Secret (it starts with ntn_ or secret_) and paste it below.

The token is stored with chrome.storage.local on this computer only — it is never synced or sent anywhere except api.notion.com.

2. Share a database with the integration

Notion integrations start with access to nothing. Open the database you want to clip into, click ••• in the top right → Connections → Connect to → pick your integration. Repeat for each database you want available.

    3. Database properties

    Fields are matched to your database properties by name and type, and you can override the mapping in the popup. A database gets the most out of the clipper with properties like these:

    Property Type Gets
    Title Title Paper title
    URL URL Page address
    DOI Text Bare DOI, e.g. 10.1038/nature12373
    BibTeX Text Full entry
    Authors Multi-select or Text Author list
    Year Number Publication year
    Journal Select or Text Journal / conference
    Cite key Text doe2023attention
    Date clipped Date When you saved it

    Only the title property is required. Anything missing is simply skipped.

    Preferences

    Disconnect

    Removes the stored token, the saved field mappings and the last used database.
