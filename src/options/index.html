Academic Clipper for Notion

Clip papers to a Notion database with their title, URL, DOI and BibTeX entry.

1. Connect your Notion workspace

  1. Open notion.so/my-integrations and create a New connection of type API key.
  2. Under Capabilities, keep read and insert content enabled.
  3. Copy the API key (it starts with ntn_ or secret_) and paste it below.

The token is stored with chrome.storage.local on this computer only — it is never synced or sent anywhere except api.notion.com.

2. Share a database with the connection

A new connection starts with access to nothing. Open the database you want to clip into, click ••• in the top right of the page — not the one on the database itself — then Connections → Connect to → pick your connection. Repeat for each database you want available.

    3. Database properties

    This is everything the clipper can write, and it is the same list the popup shows under Field mapping. Properties are matched by name and type, so close names work too (Venue for Journal, Added for Date clipped); the popup lets you re-point any of them.

    Property Type Gets
    Title Title The paper title — the only property that is required
    URL URL or Text Page address
    DOI Text, URL or Select Bare DOI, e.g. 10.1038/nature12373
    BibTeX Text The full entry
    Authors Multi-select, Text or Select Author list
    Year Number, Select, Text or Date Publication year
    Journal / Venue Select, Multi-select or Text Journal or conference
    Abstract Text Abstract, where the page publishes one
    PDF link URL, Files & media or Text Direct link to the PDF
    Entry type Select, Multi-select or Text article, inproceedings, …
    Date clipped Date When you saved it
    Cite key Text or Select kucsko2013nanometre

    Only the title property is required — a database with nothing else still works, and every property you do not have is skipped. Abstract and BibTeX can also go in the page body instead; see Preferences below.
